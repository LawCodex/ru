# О внесении изменений в Федеральный закон "О федеральном бюджете на 1999 год" (Федеральный закон от 02.01.2000 № 33-ФЗ)

РОССИЙСКАЯ ФЕДЕРАЦИЯ

**ФЕДЕРАЛЬНЫЙ ЗАКОН**

**О внесении изменений в Федеральный закон "О федеральном бюджете на 1999 год"**

Принят Государственной Думой 3 декабря 1999 года

Одобрен Советом Федерации 22 декабря 1999 года

**Статья 1.** Внести в Федеральный закон от 22 февраля 1999 года № 36-ФЗ "О федеральном бюджете на 1999 год" (Собрание законодательства Российской Федерации, 1999, № 9, ст. 1093) следующие изменения:

1. В приложении 1 "Ведомственная структура расходов федерального бюджета на 1999 год" в расходах по прямому получателю средств из федерального бюджета "Министерство сельского хозяйства и продовольствия Российской Федерации" (082):

абзацы двадцать третий и двадцать четвертый изложить в следующей редакции:

| "Формирование лизингового фонда | 082 | 08 | 01 | 342 | 214 | 625000,0 |
|---|---|---|---|---|---|---|
| Целевые дотации и субсидии | 082 | 08 | 01 | 342 | 290 | 50000,0"; |

абзац двадцать седьмой изложить в следующей редакции:

| "Государственная поддержка развития фермерства | 082 | 08 | 01 | 343 | 290 | 20000,0". |
|---|---|---|---|---|---|---|

2. В приложении 13 "Распределение ассигнований из федерального бюджета на 1999 год по разделу "Сельское хозяйство и рыболовство" функциональной классификации расходов федерального бюджета":

абзац шестой изложить в следующей редакции:

| "целевые дотации и субсидии |  |  |  |  |  | 430000,0"; |
|---|---|---|---|---|---|---|

абзац шестнадцатый изложить в следующей редакции:

| "прочие дотации |  |  |  |  |  | 0,0"; |
|---|---|---|---|---|---|---|

абзац восемнадцатый изложить в следующей редакции:

| "дотации на создание федерального фонда ветеринарных препаратов |  |  |  |  |  | 0,0"; |
|---|---|---|---|---|---|---|

абзацы двадцатый и двадцать первый изложить в следующей редакции:

| "государственная поддержка развития фермерства |  |  |  |  |  | 20000,0 |
|---|---|---|---|---|---|---|
| средства на формирование лизингового фонда |  |  |  |  |  | 675000,0". |

**Статья 2.** Настоящий Федеральный закон вступает в силу со дня его официального опубликования.
